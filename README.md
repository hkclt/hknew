# HKNew

Olá! Eu sou o ​**hkclt**​, criador do ​**HKNew**​, um projeto que ainda está em estágio inicial.

Criei o HKNew porque não gosto de ter que reescrever as mesmas configurações em todos os meus projetos Python. A ideia é facilitar esse processo criando e gerenciando projetos a partir de ​**presets**​, permitindo reutilizar configurações de forma simples.

O projeto está sendo desenvolvido ​**solo**​, por uma pessoa e sem custos. A ideia é criar algo realmente útil e que possa ser utilizado por outras pessoas.

## 🚧 Estado atual

O HKNew ainda está em desenvolvimento. Atualmente, o foco está na criação e configuração de projetos Python através de presets.

No futuro, pretendo expandir o projeto para também facilitar o gerenciamento dos projetos e suas dependências.

## 📚 Documentação

Pretendo criar uma documentação própria para o HKNew futuramente. Como também estudo ​**HTML e CSS**​, a ideia é desenvolver uma documentação simples, organizada e realmente útil para quem quiser utilizar o projeto.

## 🛠️ Desenvolvimento

O HKNew é desenvolvido de forma independente por mim, sem equipe e sem custos.

A intenção é manter o projeto simples, aberto e acessível para quem quiser utilizá-lo, estudá-lo ou contribuir.
